## About Me

I’m **Mohammad Waqas**, an AI systems engineer focused on **GPU-accelerated LLM inference, CUDA runtime engineering, and performance diagnostics for constrained NVIDIA environments**.

My current work centers on **kaggle-vllm**, where I am building tooling to make upstream vLLM reproducible and measurable on Kaggle's dual **Tesla T4 / SM75** GPUs. The project covers CUDA/PyTorch compatibility, native runtime delivery, NCCL tensor parallelism, sharded model loading, OpenAI-compatible serving, and evidence-driven inference benchmarking.

I also build systems for **LLM observability and edge inference**, spanning OpenTelemetry, llama.cpp/GGUF runtimes, Kubernetes/k3s, Prometheus, Grafana, and low-VRAM NVIDIA deployments.

- Building and benchmarking **vLLM inference on dual NVIDIA T4 GPUs**
- Investigating **tensor parallelism, NCCL communication, CUDA Graphs, memory behavior, and inference throughput**
- Engineering reproducible CUDA/PyTorch runtime and compatibility tooling
- Building **OpenTelemetry-based LLM and GPU observability**
- Developing distributed and local inference systems with CUDA, C++, Python, MPI, Kubernetes, and llama.cpp
